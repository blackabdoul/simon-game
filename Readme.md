# 🎮 Simon Game — JavaScript + jQuery

A fun, interactive memory game where the user repeats an increasingly long sequence of colors and sounds.  
Built as part of my JavaScript learning journey to strengthen DOM manipulation, event handling, and game logic skills.

---

## 🚀 Features

- 🔹 Dynamic color & sound sequence generation
- 🔹 Keypress to start the game
- 🔹 Button click detection
- 🔹 Smooth animations using jQuery
- 🔹 Level-based difficulty
- 🔹 Game over visual & sound feedback

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **jQuery**
- **VS Code / Live Server**

## 📚 How the Game Works

Press any key to start the game

Watch the color sequence light up

Click the buttons in the correct order

Each round adds a new color

A wrong click ends the game and resets the level
